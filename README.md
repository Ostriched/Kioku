# Kioku

A study app for Japanese, AP Psychology, and the SAT, Purely for personal studying purposes.

Progress is saved in your browser.

To sign in and keep progress on every device, set up accounts: see [SETUP-ACCOUNTS.md](SETUP-ACCOUNTS.md).

Install it: open the site on a phone or computer and choose "Add to Home Screen" or "Install". After the first visit it also opens without a connection.
